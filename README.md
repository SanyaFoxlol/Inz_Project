CPU Scheduling Simulator
This project is a simple CPU scheduling simulator written in Python.
It demonstrates how different scheduling algorithms manage processes in an operating system.
Algorithms
The program supports:
FCFS (First Come First Serve)
SJF (Shortest Job First)
Round Robin
Features
Process scheduling simulation
Calculation of waiting time and turnaround time
Gantt chart visualization of CPU execution
Requirements
Python 3
matplotlib
Install dependency:
pip install matplotlib
python main.py
